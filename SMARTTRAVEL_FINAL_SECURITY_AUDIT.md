# SmartTravel Final Security Audit Report

This document records the comprehensive security, authorization, financial integrity, and data protection audit across all layers of the SmartTravel platform.

## Security Risk & Remediation Matrix

| Security Area | Severity | Potential Risk / Finding | Architectural Defense & Remediation | Verification Method | Status |
| :--- | :---: | :--- | :--- | :--- | :---: |
| **Financial / Checkout Integrity** | **CRITICAL** | Client tampering with final payable price (e.g. ₹10,000 → ₹1). | Server recalculates dynamic price, taxes, coupon discounts, and price freeze authoritatively at checkout. Client amounts are ignored. | Integration tests submitting manipulated pricing payloads; verified server rejects or recalculates total. | **VERIFIED / SECURE** |
| **Refund Amount & Policy** | **CRITICAL** | Client altering refund percentage or initiating multiple refund calls. | Server-side `RefundEligibilityServiceImpl` calculates refund tiers strictly from departure timestamps. Razorpay gateway refunds use idempotency keys. | Automated refund policy tests (>48h=100%, 24-48h=50%, <24h=0%, duplicate cancellation rejection). | **VERIFIED / SECURE** |
| **Seat / Room Overselling** | **HIGH** | Concurrency race condition allowing two users to reserve the same seat or room. | MongoDB atomic compare-and-swap (`reserveSeatsAtomic`) with 15-minute hold locks. | `BookingConcurrencyIntegrationTest` (20 threads on 5 seats $\rightarrow$ exactly 5 succeed, 15 receive 409 Conflict). | **VERIFIED / SECURE** |
| **IDOR / Object Access** | **HIGH** | User accessing or cancelling another traveler's booking or ticket. | Service checks `booking.getUserId().equals(authenticatedUserId)` or `ROLE_ADMIN` on every entity fetch, update, and cancellation. | `Phase12SecurityAuditIntegrationTest` (User B accessing User A booking returns 403 Forbidden). | **VERIFIED / SECURE** |
| **JWT Authentication** | **HIGH** | Forged, malformed, or expired JWT tokens accessing protected endpoints. | JJWT 0.12.6 with HS512 secret signing, strict expiration verification, and token invalidation on logout. | Security integration tests with malformed/expired tokens; verified 401 Unauthorized response. | **VERIFIED / SECURE** |
| **Google OAuth 2.0** | **HIGH** | Spoofed Google tokens or unauthorized email claiming. | Server-side verification using Google API Client library (`GoogleIdTokenVerifier`), audience verification, and issuer check. | Auth integration tests verifying token verification and account linking. | **VERIFIED / SECURE** |
| **Review Media Upload** | **MEDIUM** | Upload of executable scripts or malicious files masquerading as images. | `LocalReviewMediaStorageServiceImpl` validates MIME type (JPEG/PNG/WebP), file extension, and strict size cap ($\le 5\text{MB}$). | Photo upload integration tests with invalid extensions and oversized payloads. | **VERIFIED / SECURE** |
| **Coupon Manipulation** | **MEDIUM** | Reusing expired coupons or bypassing minimum spend criteria. | Server-side coupon validator checks active status, expiration date, min order spend, and per-user usage limits. | Coupon service tests with expired and below-threshold booking values. | **VERIFIED / SECURE** |
| **CORS & Network Security** | **MEDIUM** | Unauthorized cross-origin requests from malicious domains. | Spring Security CORS configuration restricts origins to configured domains (localhost in dev, Vercel in prod). | CORS header verification in `SecurityConfig.java`. | **VERIFIED / SECURE** |
| **Gemini AI Boundary** | **MEDIUM** | AI hallucinating pricing, financial decisions, or leaking sensitive data. | Gemini service strictly isolated to advisory insights (travel guides, delay explanations). AI has zero access to transactional state. | Architectural code audit verifying no AI controllers interact with booking/payment services. | **VERIFIED / SECURE** |
| **Secrets & Credentials** | **HIGH** | Accidental leakage of API keys or database passwords. | All secrets (`JWT_SECRET`, `RAZORPAY_KEY_SECRET`, `MONGODB_URI`, `GEMINI_API_KEY`) parameterized via environment variables. | Git working tree audit; zero credentials committed. | **VERIFIED / SECURE** |
